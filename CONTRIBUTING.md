# Contributing

Contributions to original application code are made under the MIT licence.
Confirm that you have the right to contribute the code or assets you submit.

Before proposing a change:
- Test fresh page load before any interaction, repeated reloads, comparison on/off, divider movement, zoom/pan and small screens.
- Rebuild the standalone file with `node build.mjs`.
- Preserve Leaflet's BSD licence and map provider credits.
- Do not commit credentials, private locations, personal information or bulk map data.
- Review new service licences, privacy disclosures, usage limits and identification requirements before adding a provider.
- Keep map requests blocked until the visitor opens the map.
- Explain any new external request, stored browser data or tracking in the pull request.

Use repository issues to report bugs. Include browser/device, reproduction steps and the chosen layers; remove sensitive coordinates and private information from screenshots.
